# 嵌套世界语法

本文件说明怎样用嵌套世界技法设计片子：世界链、主角、维度梯子、转场选择和音乐。选了这个技法再读，读完再写 timeline.json。
第 6 节（节奏与音乐）和第 8 节（记忆点与动作质感）对所有片种通用；其余各节只在用嵌套世界技法时适用。

## 1. 世界链

一部片子是一条**世界链**：每个世界是另一个世界里的一个物体，或者包含另一个世界。

- 每个世界是一个 Blender 场景（`film.world('NAME', look=...)`）。物体名是 `NAME.<名字>`。
- 链长 3–5 层最合适。少于 3 层没有"穿越"感。多于 5 层观众会迷路。
- 每一层要回答一个问题："这一层是上一层里的什么？"例子：屏幕是桌上的显示器；草原是键帽里的世界。
- **至少回到一层旧世界。** 例子：结尾回到桌面，看到草原变成键帽上的微缩景。回到旧世界才有"闭环"。
- 世界的尺度要单调变化（越钻越小，或越拉越大）。尺度来回跳会让观众失去方向。

写法：先在纸上写出链，例如 `SCREEN → DESK → MEADOW → DESK`，再给每层选一个 look（见 generalize.md）。

## 2. 主角

- **只有一个主角。** 它是全片唯一的暖色（或唯一的高饱和色）。其余物体用冷色或低饱和色。观众的眼睛会一直找到它。
- 主角要出现在每个世界里，每个世界一个实例（`shapes.hero(w, 'hero', size=...)`）。各世界的实例互不相干，转场时用锚点把它们对齐。
- 主角要有表演：起跳前蓄力、落地压扁、眨眼、转头。用 `hop`、`hops`、`drop`、`blink`、`key(..., 'rotation_euler', ...)`。
- 不要用真实品牌的吉祥物。默认主角是黄色圆角方块加两个点状眼睛。

## 3. 维度梯子

UI 字形 → 像素 → 体素 → 平滑 3D →（写实环境）。每上一级，画面"更真"一层。

| 级 | 生成器 | 例子 |
|---|---|---|
| 字形 → 像素 | `assemble(start='point', point=光标)` | 光标吐出像素，拼成图标 |
| 像素 → 体素 | `lift(...)` 的挤出阶段 | 平面像素长出厚度 |
| 体素 → 平滑 | `lift(..., then=hero)` 的融化阶段 | 体素融化，平滑主角弹出 |
| 平滑 → 体素 | `assemble` 体素格子 | 分身飞成体素巨人 |
| 回到像素 | 再次 `assemble` 平面像素 | 结尾屏幕上重新出现像素图标 |

梯子要**走回去**一次（结尾回到像素或字形），形成首尾呼应。

## 4. 转场选择

规则：**转场要有来由。** 每个转场都要在画面里有一个原因：一个表面、一个动作或一个物体。

| 想表达 | 用 | 条件 |
|---|---|---|
| 钻进一个物体里的世界 | `push_in` | 物体上有一个平面（屏幕、键帽顶、相框、水面）；用 16:9 平面 |
| 发现刚才的世界只是一个物体 | `pull_out` | 同上，反向 |
| 东西从里层冲到外层 | `breach` | 锚点放在穿出的位置（`film.through()` 算出屏幕上的点） |
| 进入或退出一层，主角位置不变 | `iris` | 两边的锚点是同一个角色（或它的微缩版） |
| 换视角、换景别，同一世界 | `lens` | 镜头泡从一侧扫过，适合低机位、大景别切换 |
| 交代空间（插入镜头） | `cut` | 卡在重拍（`beat:` / `bar:`）上 |
| 时间流逝、情绪转换 | `fade` | 少用；它没有空间来由 |

- 世界内部的变化（组装、散落、生长、升维）本身就是转场。它们不需要镜头切换。
- **不要连续两个同类转场。** 例子：push_in 后面接 iris 或 cut，不接另一个 push_in。
- 转场时间是自由的。只在需要卡拍的地方用 `bar:` / `beat:`。

## 5. 锚点

锚点让两个镜头在转场时"对齐"：B 镜头的锚点在画面上的位置，等于 A 镜头的锚点位置。

- `iris`、`breach`、`lens` 默认做锚点对位（`match: true`）。引擎在转场窗口内给 B 相机加镜头偏移（lens shift），窗口结束后用 `settle` 秒（默认 1.0）回到原来的构图。
- 锚点是物体名（世界内的短名）：`"anchor": "hero"`，或两边不同 `"anchor": ["giant", "mini_giant"]`。
- 锚点用**静止的空物体**最稳。移动的锚点会让 B 相机跟着它平移。
- 微缩版对位：外层世界用 `World.instance(name, 内层集合, loc, scale)` 放一个微缩版，再放一个空物体在"微缩版里的锚点"位置。
- 两个锚点在画面上相距很远时，偏移很大，回位时像一次摇镜。这时可设 `"match": false`，或者改相机让两边构图接近。

## 6. 节奏与音乐

- 默认 30 fps，120 BPM（1 拍 0.5 s，1 小节 2 s）。
- 世界内的一个动作约 1–2 s。一个世界停留 3–6 s。
- **音乐和尺度对应：** 钻到最深一层时最安静；群体动作（组装巨人）时最响；开头和结尾用镜像的动机。
- **至少两处近乎静音**，放在大事件之前（破屏前、下潜时）。静音后的第一个声音要是全片最重要的声音之一（落地、破屏）。
- 每个可见动作都有声音。生成器自动发声音事件（`out/events.json`）；mix.py 把事件变成音效。自己加的动作用 `emit(t, 'kind')`。

## 7. 镜头

- 相机用 `w.camera('镜头id', lens=...)` 创建，用 `camera.path` / `camera.orbit` 动画。不要给相机设父物体。
- `camera.path` 的每段缓动在两端速度为 0（`smooth`、`inout`）。多段路径会在每个关键点停一下。想一气呵成，就用一段。
- 一个镜头内只做一件事：推、拉、摇或升降。
- 景深用 `dof.focus_distance`，不用 `focus_object`（push_in / pull_out 要改写焦距）。

## 8. 记忆点与动作质感

数字检查只能保证"没有错"。下面两张清单保证"好看"。按 SKILL.md 第 6.1 节的"观感"眼光逐条看。

**每个关键节拍至少有 1 个强调。** 关键节拍指：主角出场、转场的穿越点、组装完成、片名。

| 强调 | 例子 |
|---|---|
| 光 | 出场时一次闪光照亮主角；道具亮相时一道高光扫过 |
| 粒子 | 主角冲出表面时碎片飞散；落地扬尘 |
| 镜头 | 这个镜头本来的推或拉在节拍上结束，或在节拍上停住半拍（不另加第二种运动，见第 7 节） |
| 声音 | 静音后的第一个重音放在这个节拍上（第 6 节） |

每个节拍用 1–2 种画面强调（光、粒子、镜头），再配 1 个声音。强调多了就没有重点。

**动作质感。**
- 预备：每个大动作前有反向的小动作（起跳前下蹲，挥动前后拉）。
- 过冲和回弹：停下时越过终点 5–10% 再回来（`'back'` 缓动）。
- 跟随：头、尾巴、配件比身体晚 2–4 帧停下（把这个部位的关键帧整体往后移）。各部位不在同一帧达到最快（`motioncheck.py` 报 `sync`）。
- 缓入缓出：没有匀速滑行（报 `glide`），没有一帧内的急停（报 `jolt`），除非是撞击。
- 节奏：展示片比真实动作慢。动作库和视频里的原速通常太快：出原速和时长 × 1.3 两个版本，让用户选。
