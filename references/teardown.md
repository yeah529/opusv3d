# 样片拆解：leo114119_video.mp4

本文件是 opusv3d 的来源证据。它记录样片里看到的事实，以及每个事实对应引擎里的哪个能力。

## 1. 参数（实测）

- 时长 60.0 s。画幅 1920×1080。60 fps，共 3600 帧，其中 3541 帧各不相同。
- 音频响度 −15.1 LUFS。音乐 120 BPM，1 小节 = 2 s。
- 文件来自 X（Twitter）下载，经过平台重新编码（编码器标签 "Twitter-vork muxer"）。原始元数据已经没有了。

## 3. 样片背后的 5 条方法

1. **世界嵌套。** 屏幕 ⊃ 桌面 ⊃ 键盘 ⊃ 键帽 ⊃ 草地 ⊃ 分身群 ⊃ 主角。转场就是在这些层之间穿越，几乎不用硬切。
2. **主角锚点。** 只有主角用暖色，其余都是冷色。每次转场时，主角在画面上的位置两边对齐。
3. **维度梯子。** UI 字形 → 像素 → 体素 → 平滑 3D → 写实环境。结尾再走回去。
4. **转场有来由。** 传送门总是出现在场景里已有的表面上（屏幕、键帽顶面），由涟漪引出。
5. **音乐和尺度对应。** 钻到最深的一层时音乐最安静。群组装时最响。开头和结尾用镜像的闪音。

## 5. opusv3d 没有照搬的部分

- 样片主角是 Claude Code 的吉祥物。opusv3d 只保留手法。冒烟片用通用的黄色圆角方块主角（`shapes.hero`）。
- 样片是 60 fps。opusv3d 默认 30 fps（渲染时间减半）。交付时可在 timeline.json 改成 60。
- 写实草地和焦散：EEVEE 只能做到风格化，写实度低一档。关键镜头可在 timeline.json 里给该镜头写 `"engine": "cycles"`。
